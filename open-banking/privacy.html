Politique de confidentialité

Application : dashboard-perso

Cette application est un projet personnel développé et utilisé exclusivement par son développeur, Louis Hanquiez, pour consulter ses propres données bancaires (soldes, transactions) via des API d'agrégation bancaire (Open Banking / PSD2, fournies par Enable Banking).

Aucune donnée n'est collectée, stockée sur un serveur tiers, ni partagée avec un tiers autre que le fournisseur d'agrégation nécessaire à la connexion bancaire elle-même. Les données consultées ne servent qu'à l'affichage, pour le développeur lui-même, dans son propre tableau de bord de suivi financier personnel.

Cette application n'est pas destinée à un usage public ou commercial.

Contact pour toute question relative à la protection des données : l.hanquiez22@gmail.com
